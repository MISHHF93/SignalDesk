# SignalDesk Master Prompt (Constant Wrapper)

This file is the portable, persistent "constitution" for any coding agent
working on SignalDesk — Claude, Codex, Grok, or otherwise. It exists so
individual task prompts don't need to re-explain what SignalDesk is, what
architecture already exists, or what "done" means.

- **Claude Code** already loads `CLAUDE.md` automatically at the start of
  every session — that file is the concise, curated version of the same
  discipline captured here. You do not need to paste this file's contents
  when working with Claude Code in this repo.
- **Any other agent** (Codex, Grok, ChatGPT, etc.) that does not
  auto-load `CLAUDE.md` should get the **Master Wrapper** section below
  pasted above every task-specific prompt, using the template in
  "How to use."

Keep this file and `CLAUDE.md` in sync when the operating principles
change — treat this as the verbose source, `CLAUDE.md` as the distilled
one.

## How to use

```text
SIGNALDESK MASTER WRAPPER
[paste the full "Master Wrapper" section below]

CURRENT TASK
<describe the specific task>

SUCCESS CRITERIA
- <criterion>
- <criterion>
...
```

Example:

```text
SIGNALDESK MASTER WRAPPER
[master wrapper]

CURRENT TASK
Implement the QuickBooks connector completely.

SUCCESS CRITERIA
- OAuth works
- company selection works
- invoices synchronize
- payments synchronize
- webhooks/incremental sync work where supported
- normalized objects populate Business Graph
- coverage updates
- relevant Signals can consume the data
- reconnect/reauthorize/disconnect work
- Integration Hub reflects real state
- tests pass
- readiness documentation updated
```
